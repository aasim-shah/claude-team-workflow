# ship-workflow

Work with Claude the way the Claude Code team does. This plugin gives you approval-gated feature work, evidence-backed PRs and review replies, multi-agent review with a validator per finding, and hardened Claude-in-CI templates.

Unofficial. It is not affiliated with Anthropic.

- Skill: `shipping-like-claude-code-team`. It loads automatically for features, PRs, reviews and CI agents.
- Commands: `/ship-workflow:feature`, `review-diff`, `ship-pr`, `reply-review` and `setup-repo`.
- Repo installer: `scripts/init-repo.sh --commands | --ci | --all [--dry-run] [--force] [dir]`

Full documentation: https://github.com/aasim-shah/claude-team-workflow
